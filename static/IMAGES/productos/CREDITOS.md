# Créditos de las imágenes de demostración

Las fotos de `static/IMAGES/productos/` son **imágenes de stock libres** usadas
solo para la demo del catálogo (estilo pastelería artesanal). No son fotos de
productos reales de Dulce Arte.

| Archivo | Uso en el catálogo |
|---|---|
| `chocolate.jpg` | Torta de chocolate |
| `cheesecake.jpg` | Cheesecake de frutilla |
| `manjar.jpg` | Torta de manjar |
| `zanahoria.jpg` | Torta de zanahoria |
| `cupcakes.jpg` | Caja de cupcakes |
| `default.jpg` | Respaldo para productos sin foto |

Antes de publicar la tienda en producción, reemplázalas por fotografías propias
o conserva la atribución que corresponda a la licencia original del banco de
imágenes. El admin de Django permite subir una foto por producto en
**Productos → Imagen del catálogo**; la imagen subida tiene prioridad sobre la
ruta de demostración.
